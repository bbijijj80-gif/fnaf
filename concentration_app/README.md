# 🎯 Concentration Hub - Центр Концентрации

Приложение для повышения продуктивности и концентрации, состоящее из 10 специализированных модулей.

## 📋 Состав приложения

### Главный лаунчер (ConcentrationHub.exe)
Центральный интерфейс для запуска всех модулей с красивым современным дизайном.

### 10 Модулей:

| № | Модуль | Файл | Описание |
|---|--------|------|----------|
| 1 | 🍅 Таймер Помодоро | module1_pomodoro.exe | Классический таймер 25/5 для работы |
| 2 | 🔊 Белый шум | module2_white_noise.exe | Генератор белого шума для фокусировки |
| 3 | 🚫 Блокировщик сайтов | module3_site_blocker.exe | Временная блокировка отвлекающих сайтов |
| 4 | 🧘 Дыхательные упражнения | module4_breathing.exe | Упражнения для снятия стресса |
| 5 | ✅ Трекер задач | module5_task_tracker.exe | Простой список задач на сессию |
| 6 | 📊 Статистика фокуса | module6_stats.exe | Отслеживание времени концентрации |
| 7 | 📝 Минималистичный редактор | module7_editor.exe | Текстовый редактор без отвлечений |
| 8 | ☕ Напоминания о перерывах | module8_break_reminder.exe | Регулярные напоминания отдохнуть |
| 9 | 💡 Цитаты для мотивации | module9_quotes.exe | Случайные мотивирующие цитаты |
| 10 | 🌙 Тёмная тема экрана | module10_dark_screen.exe | Фильтр синего света для глаз |

## 🚀 Установка и запуск

### Требования
- Windows 10/11
- Python 3.8 или выше

### Быстрый старт

1. **Установите зависимости:**
```bash
pip install customtkinter pyinstaller
```

2. **Запустите главный лаунчер:**
```bash
python main_launcher/main.py
```

### Компиляция в EXE

Для создания автономных исполняемых файлов:

```bash
build.bat
```

Или вручную:
```bash
# Главный лаунчер
pyinstaller --onefile --windowed --name "ConcentrationHub" main_launcher/main.py

# Модули (для каждого)
pyinstaller --onefile --windowed modules/module1_pomodoro.py
# ... повторить для всех 10 модулей
```

## 💡 Особенности

- **Современный дизайн** - тёмная тема, плавные анимации
- **Модульность** - каждый модуль работает независимо
- **Кроссплатформенность** - работает на Windows 10 и 11
- **Лёгкость** - минимальные требования к системе
- **Гибкость** - настройка параметров под себя

## ⚠️ Примечания

- Модуль блокировки сайтов требует прав администратора
- Для работы белого шума нужны библиотеки `sounddevice` и `numpy`
- Некоторые функции могут отличаться на разных версиях Windows
