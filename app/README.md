# Приложение с 10 модулями и главным интерфейсом

## Структура проекта

```
app/
├── main.py              # Главный файл с интерфейсом
└── modules/             # Папка с 10 модулями
    ├── task1.py         # Калькулятор
    ├── task2.py         # Генератор паролей
    ├── task3.py         # Конвертер валют
    ├── task4.py         # Генератор случайных чисел
    ├── task5.py         # Погода (симуляция)
    ├── task6.py         # Анализ текста
    ├── task7.py         # Таймер/секундомер
    ├── task8.py         # Заметки
    ├── task9.py         # Системная информация
    └── task10.py        # QR-генератор
```

## Запуск приложения

### Запуск главного интерфейса:
```bash
cd app
python3 main.py
```

### Запуск отдельных модулей:

1. **Калькулятор**: `python3 modules/task1.py "2+2*2"`
2. **Генератор паролей**: `python3 modules/task2.py 16`
3. **Конвертер валют**: `python3 modules/task3.py 100 USD EUR`
4. **Генератор случайных чисел**: `python3 modules/task4.py 1 100 5`
5. **Погода**: `python3 modules/task5.py "Москва"`
6. **Анализ текста**: `python3 modules/task6.py "Привет мир"`
7. **Таймер**: `python3 modules/task7.py stopwatch` или `python3 modules/task7.py 5`
8. **Заметки**: `python3 modules/task8.py "текст заметки"` или `python3 modules/task8.py list`
9. **Системная информация**: `python3 modules/task9.py`
10. **QR-генератор**: `python3 modules/task10.py "данные"`

## Требования

Для работы требуется Python 3.x и библиотека psutil:
```bash
pip install psutil
```

## Описание модулей

| № | Модуль | Описание |
|---|--------|----------|
| 1 | Калькулятор | Выполняет математические выражения |
| 2 | Генератор паролей | Создаёт случайные пароли заданной длины |
| 3 | Конвертер валют | Конвертирует между USD, EUR, GBP, RUB, JPY |
| 4 | Генератор случайных чисел | Генерирует числа в диапазоне |
| 5 | Погода | Симуляция данных о погоде |
| 6 | Анализ текста | Подсчёт слов, символов, предложений |
| 7 | Таймер | Таймер и секундомер |
| 8 | Заметки | Добавление и просмотр заметок |
| 9 | Системная информация | Информация об ОС, CPU, RAM, диске |
| 10 | QR-генератор | Генерация хеша для QR-кодов |
