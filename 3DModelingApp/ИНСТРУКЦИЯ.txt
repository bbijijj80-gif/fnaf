# Инструкция по запуску

## Быстрый старт в Visual Studio

1. **Откройте решение**
   - Запустите Visual Studio 2022
   - Файл → Открыть → Решение
   - Выберите файл: `3DModelingApp.sln`

2. **Дождитесь загрузки пакетов**
   - Visual Studio автоматически загрузит NuGet пакеты (HelixToolkit.Wpf)
   - Это может занять несколько секунд при первом запуске

3. **Запустите приложение**
   - Нажмите клавишу **F5** или
   - Нажмите кнопку **"Запустить"** (зеленый треугольник) или
   - Меню: Отладка → Запуск отладки

4. **Работа с приложением**
   - Добавляйте 3D модели кнопками на панели инструментов
   - Вращайте, масштабируйте сцену мышкой
   - Экспортируйте в STL или OBJ для 3D печати

## Альтернативный способ (через командную строку)

Если у вас установлен .NET 6.0 SDK:

```bash
cd /workspace/3DModelingApp
dotnet restore
dotnet build
dotnet run
```

## Возможные проблемы и решения

### Ошибка: "Не удается найти HelixToolkit"
- Убедитесь, что интернет подключен
- Правой кнопкой на решении → "Восстановить NuGet пакеты"

### Ошибка: ".NET 6.0 не установлен"
- Скачайте с: https://dotnet.microsoft.com/download/dotnet/6.0
- Установите .NET 6.0 SDK

### Приложение не запускается на Linux/Mac
- Это WPF приложение работает только на Windows
- Для кроссплатформенной версии потребуется Avalonia UI

## Системные требования

- **ОС**: Windows 10/11 (64-bit)
- **.NET**: 6.0 или новее
- **RAM**: минимум 2 GB
- **GPU**: видеокарта с поддержкой DirectX 9.0c+
