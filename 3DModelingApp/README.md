# 3D Modeling Application для 3D принтеров

## Описание
Приложение для создания и экспорта 3D моделей в форматы STL и OBJ, предназначенное для работы с 3D принтерами.

## Требования
- Windows 10/11
- .NET 6.0 SDK или новее
- Visual Studio 2022 (рекомендуется) или Visual Studio Code

## Установка

### Вариант 1: Visual Studio 2022
1. Откройте файл `3DModelingApp.sln` в Visual Studio
2. Дождитесь автоматической загрузки NuGet пакетов
3. Нажмите F5 или кнопку "Запустить" для компиляции и запуска

### Вариант 2: Командная строка
```bash
cd 3DModelingApp
dotnet restore
dotnet build
dotnet run
```

## Функционал

### Создание 3D моделей
- **Куб** - добавляет синий куб с поворотом
- **Сфера** - добавляет красную сферу
- **Цилиндр** - добавляет зеленый цилиндр

### Экспорт файлов
- **STL** - стандартный формат для 3D печати
- **OBJ** - универсальный 3D формат

### Дополнительные возможности
- Очистка сцены
- Счетчик созданных моделей
- 3D навигация (вращение, масштабирование, панорамирование)
- Отображение системы координат

## Управление в 3D viewport
- **Левая кнопка мыши** - вращение камеры
- **Правая кнопка мыши** - панорамирование
- **Колесо мыши** - масштабирование
- **Ctrl + левая кнопка** - зум

## Технические детали
- **Фреймворк**: WPF (.NET 6.0)
- **3D движок**: Helix Toolkit WPF
- **Язык**: C#
- **Экспортеры**: STL, OBJ

## Примечания
- Все созданные модели можно экспортировать для использования в слайсерах для 3D печати
- Поддерживается создание неограниченного количества моделей
- При экспорте все модели сцены объединяются в один файл
