# WinTools - Приложение с 10 инструментами для Windows

## Описание
Приложение состоит из главного меню (MainApp) и 10 отдельных EXE-файлов с различными утилитами. Работает на Windows 10 и Windows 11.

## Структура проекта
```
WinToolsApp/
├── WinToolsApp.sln          # Решение Visual Studio
├── MainApp/                 # Главное приложение с интерфейсом
│   ├── MainApp.csproj
│   └── MainApp.cs
└── Tools/                   # 10 инструментов
    ├── Tool1_SystemInfo.csproj    # Информация о системе
    ├── Tool1_SystemInfo.cs
    ├── Tool2_Calculator.csproj    # Калькулятор
    ├── Tool2_Calculator.cs
    ├── Tool3_NotePad.csproj       # Блокнот
    ├── Tool3_NotePad.cs
    ├── Tool4_Clock.csproj         # Часы
    ├── Tool4_Clock.cs
    ├── Tool5_ColorPicker.csproj   # Выбор цвета
    ├── Tool5_ColorPicker.cs
    ├── Tool6_RandomGen.csproj     # Генератор случайных чисел
    ├── Tool6_RandomGen.cs
    ├── Tool7_Stopwatch.csproj     # Секундомер
    ├── Tool7_Stopwatch.cs
    ├── Tool8_TaskManager.csproj   # Диспетчер задач
    ├── Tool8_TaskManager.cs
    ├── Tool9_FileSearch.csproj    # Поиск файлов
    ├── Tool9_FileSearch.cs
    ├── Tool10_WeatherMock.csproj  # Погода (демо)
    └── Tool10_WeatherMock.cs
```

## Инструменты
1. **Информация о системе** - показывает версию ОС, количество ядер процессора, память
2. **Калькулятор** - обычный калькулятор с базовыми операциями
3. **Блокнот** - простой текстовый редактор с открытием/сохранением файлов
4. **Часы** - отображение текущего времени в реальном времени
5. **Выбор цвета** - инструмент для выбора цвета через диалог
6. **Генератор случайных чисел** - генерация случайных чисел от 0 до 1000
7. **Секундомер** - старт, стоп, сброс
8. **Диспетчер задач** - просмотр и завершение процессов
9. **Поиск файлов** - поиск файлов на рабочем столе
10. **Погода (демо)** - демонстрация погодной информации

## Сборка в Visual Studio

### Требования
- Windows 10/11
- Visual Studio 2022 (или новее)
- .NET 6.0 SDK

### Инструкция по сборке
1. Откройте GitHub и скачайте этот репозиторий
2. Откройте `WinToolsApp.sln` в Visual Studio
3. Нажмите **F6** или выберите **Сборка → Сборка решения**
4. Все 11 EXE-файлов будут скомпилированы автоматически

### Расположение скомпилированных файлов
После сборки файлы будут находиться в папках:
- `MainApp/bin/Debug/net6.0-windows/MainApp.exe`
- `Tools/bin/Debug/net6.0-windows/Tool*.exe`

### Развёртывание
Для корректной работы главного приложения:
1. Скопируйте `MainApp.exe` в нужную папку
2. Создайте папку `Tools` рядом с `MainApp.exe`
3. Скопируйте все 10 `Tool*.exe` в папку `Tools`

## Примечания
- Все инструменты работают независимо друг от друга
- Главный интерфейс позволяет запускать любой инструмент из списка
- Требуется .NET 6.0 Runtime для запуска на целевых машинах
