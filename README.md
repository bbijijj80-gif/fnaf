# 3D Printer Modeler - Приложение для 3D моделирования

## Описание
Приложение для создания и редактирования 3D моделей, предназначенных для 3D печати. Поддерживает создание базовых геометрических примитивов и экспорт в популярные форматы.

## Требования
- **Visual Studio 2022** (или новее)
- **.NET 6.0 SDK** или новее
- **Windows 10/11**

## Установка

1. Откройте файл `ModelingApp3D.sln` в Visual Studio 2022
2. При первом открытии NuGet автоматически загрузит необходимые зависимости:
   - HelixToolkit.Wpf (для 3D визуализации)
   - System.Numerics.Vectors

## Запуск
Нажмите **F5** в Visual Studio или выберите меню **Отладка → Запустить отладку**

## Функционал

### Создание 3D моделей
- ➕ **Куб** - создание куба с настраиваемым размером
- ➕ **Сфера** - создание сферы с настраиваемым радиусом
- ➕ **Цилиндр** - создание цилиндра
- ➕ **Конус** - создание конуса
- ➕ **Тор (Пончик)** - создание тора

### Настройки
- **Размер** - ползунок для изменения размера создаваемых объектов (0.5 - 5.0)
- **Цвет** - выбор цвета из палитры (8 цветов на выбор)

### Управление сценой
- 🗑️ **Удалить выбранное** - удаление выделенного объекта
- 🗑️ **Очистить всё** - очистка всей сцены
- 🔄 **Сброс камеры** - возврат камеры в исходное положение

### Экспорт моделей
- 📤 **STL** - бинарный формат STL (совместим со всеми слайсерами)
- 📤 **OBJ** - формат OBJ с поддержкой текстур
- 📤 **3MF** - информация о поддержке формата

### Навигация в 3D пространстве
- 🖱️ **ЛКМ + перетаскивание** - вращение камеры
- 🖱️ **ПКМ + перетаскивание** - перемещение камеры
- 🖱️ **Колесо мыши** - масштабирование

## Технические детали

### Используемые технологии
- **WPF (Windows Presentation Foundation)** - для создания пользовательского интерфейса
- **Helix Toolkit** - библиотека для 3D визуализации
- **C# 10** - язык программирования
- **.NET 6** - платформа выполнения

### Поддерживаемые форматы экспорта
1. **STL (Stereolithography)** - наиболее популярный формат для 3D печати
   - Бинарный формат
   - Совместим с Cura, PrusaSlicer, Simplify3D и другими слайсерами

2. **OBJ (Wavefront Object)** - универсальный 3D формат
   - Поддержка текстур и материалов
   - Широко используется в 3D моделировании

## Возможные расширения
- Импорт существующих STL/OBJ файлов
- Редактирование вершин и граней
- Булевы операции (объединение, вычитание, пересечение)
- Параметрическое моделирование
- Прямая отправка на 3D принтер
